# Stepwise AI

**Learn without the overwhelm.**

Stepwise AI is a learning roadmap platform designed to break down complex learning goals into manageable steps. Instead of facing an entire subject at once, learners can follow a structured path, complete tasks, and track their progress one step at a time.

## Features

- **Structured Learning Roadmaps:** Explore learning paths for DSA, Web Development, Python, and UI/UX Design.
- **Step-by-Step Learning:** Break large learning goals into smaller, actionable tasks.
- **DSA Learning Demo:** A detailed Data Structures and Algorithms roadmap featuring mini-lessons, practice tasks, checkpoints, and learning resources.
- **Progress Tracking:** Keep track of completed learning steps.
- **Interactive Interface:** A responsive interface with animations and theme customization.
- **Demo Mode:** Explore predefined learning roadmaps without requiring an AI API key.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (LTS version recommended)
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone <YOUR_GITHUB_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd stepwise-ai-next
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## How to Use

1. Open Stepwise AI in your browser.
2. Choose a learning path, such as Data Structures and Algorithms.
3. Explore the roadmap and follow the learning steps.
4. Complete the practice tasks and checkpoints.
5. Track your progress as you work through the roadmap.

## Current Demo Scope

The current demo uses predefined learning content and does not require external AI API calls. The DSA learning path is the primary detailed demonstration, while other learning paths provide additional roadmap options.
